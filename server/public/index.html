OpenLPS Update Service

Pré-lançamento seguro

O serviço estático do OpenLPS está preparado para distribuir manifestos de atualização assinados e documentação pública.

Atualizações remotas permanecem desativadas até a publicação de manifest.json e manifest.json.sig válidos. Nenhuma chave privada é armazenada neste servidor.

Remote updates remain disabled until a valid signed manifest is published.

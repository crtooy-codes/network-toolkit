# OpenLPS code of conduct

OpenLPS is a security research project. Participation must stay professional,
lawful and focused on authorized testing.

## Expected behavior

- Be respectful and constructive in issues, pull requests and discussions.
- Keep reports technical, reproducible and scoped.
- Credit prior work and third-party components correctly.
- Remove secrets, personal data and private network details before sharing logs.
- Discuss offensive-security behavior only in authorized laboratory contexts.

## Unacceptable behavior

- Harassment, threats, hate speech or personal attacks.
- Sharing stolen credentials, private data or unauthorized target details.
- Requests or instructions intended for unauthorized access.
- Publishing private keys, tokens, passwords or recovery material.
- Evading the release process or asking maintainers to ship unreviewed binaries.

## Enforcement

Maintainers may edit, hide or remove content that violates this policy. Repeated
or severe violations may result in blocked participation in the project.

Security issues that include sensitive details should be reported privately
through the repository security reporting channel when available.
